# Repository Restructure Plan

This plan summarizes opportunities to streamline the current repository layout. It focuses on consolidating duplicate modules, clarifying distribution assets, and organizing artifacts generated by automation.

## Current Observations

- Duplicate core modules exist both at the repository root (`combat.py`, `player.py`, etc.) and inside `distribution/`. Maintaining both copies increases drift risk.
- GUI snapshots live directly under `gui_snapshots/`, separate from documentation where they are referenced.
- Automation outputs (analysis reports, screenshots) mix with source artifacts.
- Asset directories contain only game-ready files after duplicate removal, which is good.

## Proposed Changes (Follow-up Tasks)

1. **Consolidate Core Code**
   - Designate either the root-level modules or `distribution/` as the authoritative source.
   - Remove the redundant set once the preferred location is confirmed.
   - Update imports throughout to point to the canonical modules.

2. **Organize Snapshots & Reports**
   - Move `gui_snapshots/` under `docs/` (`docs/gui_snapshots/`) to keep documentation assets together.
   - Store automation outputs (e.g., `.cursor/analysis_report.json`) in `docs/reports/` with README pointers.

3. **Create `src/` Directory (Optional)**
   - If future expansion occurs, relocate core code to a `src/` directory.
   - Adjust tooling (PYTHONPATH, launch scripts) accordingly.

4. **Standardize Asset Naming & Metadata**
   - Maintain the underscore naming convention (`cave_entrance.png`).
   - Add a `docs/assets/backgrounds.md` describing each background and scene mapping.

5. **Clean Build Artifacts Periodically**
   - Add `.pyc` and `__pycache__/` to `.gitignore` if not already present.
   - Provide a cleanup utility (PowerShell/Bash) invoked by agents before packaging.

## Next Steps

- Prioritize consolidation of duplicate modules (`distribution/` vs root). This is the largest source of confusion.
- Align documentation and automation assets under `docs/` to keep the repository tidy.
- Schedule follow-up tasks for each bullet above so agents can tackle them in parallel.
